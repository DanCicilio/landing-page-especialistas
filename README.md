## 🚀 Deploy no Vercel

1. Faça push para GitHub
2. Conecte o repositório no [Vercel](https://vercel.com)
3. Cada push automáticamente redeploy

## 📝 Como Atualizar

### Adicionar novo portfólio:
1. Edite a seção `<!-- PORTFOLIO SECTION -->` no `index.html`
2. Adicione um novo card com:
   ```html
   <div class="project-card" style="...">
     <h3>Nome do Projeto</h3>
     <p>Descrição</p>
     <a href="URL">Explorar Projeto →</a>
   </div>
   ```
3. Commit e Push - Vercel atualiza automaticamente!

### Alterar cores:
- Hero: `background: linear-gradient(135deg, #0f172a 0%, ...)`
- Serviços: Gradients dos cards
- CTA: `background: linear-gradient(135deg, #6366f1 0%, ...)`

### Alterar textos:
- Busque e altere diretamente no `index.html`
- Mantenha a estrutura HTML intacta
